# Irish Theory BR — Categoria BW

Aplicativo independente de estudo para a prova teórica de **carro e trator na Irlanda**.

- 135 questões autorais de prática com enunciados e alternativas em inglês e português brasileiro.
- Explicações em português, estudo por assunto, revisão de erros e histórico local.
- Simulado de 40 perguntas, 45 minutos e meta de 35 acertos.
- Funciona como site estático no GitHub Pages; parte do conteúdo pode funcionar offline após a primeira visita.

**Atenção:** não é um produto oficial da RSA, e as questões não são reproduções licenciadas do exame. Utilize também as fontes oficiais em https://www.rsa.ie/services/learner-drivers/resources/rules-of-the-road.

## Publicação

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)**. URL prevista: https://marioenio.github.io/CNH.ie/ (somente após ativação e publicação confirmadas pelo GitHub).
